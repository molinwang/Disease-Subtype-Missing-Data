# Disease Subtype Analysis with Missing Data

Statistical methods and R/SAS code developed by Dr. Molin Wang's group and collaborators for disease subtype analysis with missing subtype or biomarker information.

## Available methods

| Method | Language | Purpose |
| --- | --- | --- |
| [Inverse probability weighting (IPW)](IPW/) | SAS | Estimate exposure–subtype associations and test heterogeneity across disease subtypes when subtype data are missing. |
| [Augmented inverse probability weighting (AIPW)](AIPW/) | R | Analyze missing disease subtypes or competing risks defined by multiple biomarkers, incorporating partially observed biomarker data. |
